# 1. Introducción

El verso en NO&DO, parte del individuo, el sujeto como unidad central.

Si el sujeto no tiene historia, inquietudes o necesidades, este no existe.

El individuo da forma a las historias, a las relaciones, las asociaciones, inicia y forma parte de las actividades y eventos.

---

# 2. Principios Fundamentales

## 2.1 La identidad

Cada sujeto, como individuo, tiene identidad propia, individual y no se repite o duplica.

La identidad se constituye a partir de una serie de datos, Administrativos, Sociales, Personales e Historicos.

Los datos Administrativos del individuo lo conocemos como FILIACION, son aquellos datos que una administracion, toma del sujeto para formar un censo, su objetivo es identificarlo como unico dentro del sistema.

Los datos Sociales son aquellos que caracterizan al individuo dentro de una sociedad, asociando su nombre con una actividad, un grupo, un status o una categoria.

Los datos Personales, son aquellos que el sujeto guarda para si mismo, puede o no conocerlos y no los comparte abiertamente a menos que lo necesite, puden ser intrinsecos o transitorios, entran aqui elementos que dan caracter al sujeto, como una dolencia o discapacidad, una actitud, una pertenencia, ideologia, creencia, deseos, un delito, una infidelidad, etc.

Los datos Historicos son aquellos que dibujan la trayectoria del sujeto, tales como los trabajos que realizo, eventos en los que participo o formo parte, parejas que tuvo, ascendencia, etc.

Esta base, diferencia dos bloques estructurados, Identidad Administartiva (FILIACION) y la identidad PERSONAL.

# 3 IDENTIDAD PERSONAL
La identidad personal del sujeto se constituye a partir de una serie de respuestas a las preguntas, ¿Que piensa?, ¿Que quiere?, ¿Que hace?, ¿Que necesita?, ¿Donde esta? y ¿A donde va?.
